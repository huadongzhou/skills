**读法**：任一领域，九维都有归属，要么展开（●）、要么简述（○）、要么有明确去向地并入（⊕）。没有「无家可归」的维度，也没有为某领域新造的维度。简述维度只交一句定位与一条反转，**不必凑三件套**；反转一律须满足 SKILL.md「第二步」的来源口径（单源按 SKILL.md 异常表降级）；无来源支撑的维度按留白标记留白，不产出反转与三件套。

## 各领域反转主色调

反转的结构统一（你以为 A，其实 B，因为 C），但**反差从哪来**随领域不同：

| 领域 | 反转主色调 |
|---|---|
| T1 技术产品 | 名义定位 ≠ 实际定位；瓶颈 ≠ 宣传点；能力 ≠ 前提 |
| T2 组织公司 | 对外叙事 ≠ 内部账本；表面业务 ≠ 真实利润来源 |
| T3 制度规则 | 立法初衷 ≠ 实际效果；副作用常是主作用 |
| T4 概念理论 | 流行版本 ≠ 原始定义；适用范围比宣称窄 |
| T5 作品语言 | 作者意图 ≠ 文本效果；经典是被建构的 |
| T6 事件现象 | 单一归因 ≠ 多因；报道框架 ≠ 真相 |
| P1 人物 | 公众形象 ≠ 真实动机；天才叙事 ≠ 时代与运气 |
| N1 物质材料 | 直觉性质 ≠ 真实性质（尺度/量子）；常见用途 ≠ 最强用途 |
| N2 生物系统 | 拟人化直觉 ≠ 真实机制；「低级」其实精妙 |
| N3 地理天文 | 尺度颠覆直觉；观测到的是过去 |
| F1 数学形式 | 直觉 ≠ 严格；简单对象 ≠ 简单性质 |

**在世个人加固**：涉及在世个人的反转，来源须为一手自述或具名可核验的报道；仅凭二手推测的动机类结论（如「真实动机」），改归「争议」维度或不写。

## 多领域实体

多数实体跨领域，用**主领域定骨架 + 次领域补维度或改读法**，最多标三个：

| 实体 | 领域标记 | 骨架调整 |
|---|---|---|
| OpenAI | T2 主 + T4 次 | 骨架走组织公司；「机制」增补其技术主张的读法 |
| 区块链 | T1 主 + T4 次 + T6 次 | 技术骨架；「动力」兼收投机动机；「争议」兼收监管之争 |
| 围棋 | T5 主 + T3 次 | 作品/规则骨架；「机制」读作规则与棋理 |
| 咖啡因 | N1 主 + N2 次 | 物质骨架；「机制」读作生理作用 |
| 图灵 | P1 主 + F1 次 | 人物骨架；「机制」读作其方法论 |
