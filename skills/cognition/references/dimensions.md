# 维度指南

九个维度的填法。每维给七项：**要回答**（把待答问题拆细）、**社会/人造读法**、**自然/形式读法**、**查什么**（检索方向）、**反转藏哪**（这一维最容易出反转的缝）、**黑话样本**（供对照，不照抄）、**好案例**（什么样的实例算合格）。

## 1. 身份 — 它是什么

- **要回答**：它的定义；它自居的定位；它实际扮演的角色；它取代或对标了什么。
- **社会/人造读法**：名义定位 vs 实际定位。
- **自然/形式读法**：定义与分类地位（分类学位置、数学定义与所属分支）。
- **查什么**：官方定义与自我描述、真实用法、前身与被替代者、分类归属。
- **反转藏哪**：名义定位与实际定位之间的缝。官方说它是什么，用户拿它干什么，两者常常不同。
- **黑话样本**：随领域，如 SaaS 的 ARR / PMF、大模型的 token / 幻觉、分类学的模式种。
- **好案例**：一个同时展示「名义」与「实际」的具体事件，让读者一眼看见那条缝。

## 2. 构成 — 它由什么组成

- **要回答**：由哪些部分或成分组成；各部分各担什么角色；有哪几个层级或尺度。
- **社会/人造读法**：部件 / 角色 / 分工（部门、模块、岗位）。
- **自然/形式读法**：成分 / 结构 / 尺度层级（原子排列、生理结构、地层分层）。
- **查什么**：架构图、组织图、成分分析、结构解析、分层模型。
- **反转藏哪**：看似核心的部件其实可替换；真正不可替代的那块，往往不在介绍里。
- **黑话样本**：随领域，如系统的耦合 / 解耦、材料的晶格、生物的器官系统。
- **好案例**：一次「拆掉某部件就崩、拆掉宣传里的核心却没事」的对照。

## 3. 谱系 — 它从哪来

- **要回答**：诞生或形成的背景与要解决的问题；关键转折点；前代同类尝试为什么失败。
- **社会/人造读法**：诞生背景与关键转折。
- **自然/形式读法**：起源与形成过程（演化史、地质年代、数学史）。
- **查什么**：时间线里程碑、创始人访谈、被淘汰的前代方案、演化树或年代序列。
- **反转藏哪**：它是旧问题的新解，并非凭空出现。放回旧问题脉络，很多「新特性」其实是旧约束的解法。
- **黑话样本**：随领域，如 RAG 的 grounded generation、演化的趋同进化。
- **好案例**：一个「前人失败、它成功」的对照，说明变的是约束条件而非想法本身。

## 4. 机制 — 它怎么运转

- **要回答**：核心因果链（输入 → 处理 → 输出）；关键环节各负责什么；这套机制成立的前提。
- **社会/人造读法**：流程 / 业务 / 技术原理。
- **自然/形式读法**：规律 / 性质 / 动力学（物理化学规律、生理机制、证明逻辑）。
- **查什么**：原理性说明、架构文档、拆解类长文、故障与报错复盘。
- **反转藏哪**：被宣传的环节与真正决定结果的环节不一致；最闪亮的一环，往往不是瓶颈。
- **黑话样本**：随领域，如检索的召回 / 重排、数据库的 MVCC、流体力学的雷诺数。
- **好案例**：一次能暴露「真正瓶颈」的性能问题或事故复盘。

## 5. 坐标 — 它与什么相连

- **要回答**：上游依赖与下游应用；替代者与竞争者；与谁常被混淆；它在什么体系里、占什么位置。
- **社会/人造读法**：上下游 / 竞合 / 依附。
- **自然/形式读法**：所处体系 / 相互作用（生态位、系统耦合、数学分支中的位置）。
- **查什么**：产业链图谱、竞品对比、集成与被集成关系、生态位或相互作用网络。
- **反转藏哪**：看似竞争，实为共生或依附；很多「对手」其实是它的分发渠道或依赖方。
- **黑话样本**：随领域，如云厂商的 lock-in、生态位重叠、开源的 fork / 上游。
- **好案例**：一次「竞品其实靠它活着」或「替代方案最终被收编」的真实事件。

## 6. 动力 — 谁在推动它

- **要回答**：谁是受益者；谁买单；什么在驱动它；被贩卖的叙事是什么。
- **社会/人造读法**：利益相关方与动机。
- **自然/形式读法**：成因与驱动力（常并入「机制」或「谱系」，见覆盖矩阵）。
- **查什么**：融资与股权结构、定价与成本、游说与标准之争、营销话术与实际交付的对比。
- **反转藏哪**：被贩卖的叙事与真实动机之间的落差。台上讲的是价值，台下算的是账。
- **黑话样本**：随领域，如 VC 的 term sheet、平台的两端补贴、标准的锁定效应。
- **好案例**：一次「宣传口径与商业动机明显错位」的公开事件（发布会、财报、监管文件）。

## 7. 边界 — 它做不到什么

- **要回答**：能力上限；典型失败模式；不适用或会反噬的场景。
- **社会/人造读法**：能力上限与失效条件。
- **自然/形式读法**：适用条件与极限（稳定条件、可判定性、观测极限）。
- **查什么**：官方 limitations 章节、事故与故障报告、基准测试失败项、用户抱怨。
- **反转藏哪**：宣称的能力与成立前提之间的差。能力本身为真，但前提苛刻，换场景即失效。
- **黑话样本**：随领域，如模型的分布外泛化、系统的单点故障、策略的过拟合。
- **好案例**：一次「在宣传场景内成功、在真实场景里翻车」的对照。

## 8. 争议 — 分歧在哪

- **要回答**：尚在争论的开放问题；专家的分歧点；被当成共识、其实未定的部分。
- **社会/人造读法**：路线与标准之争。
- **自然/形式读法**：未解问题与分歧（未复现结果、开放猜想）。
- **查什么**：对立双方的原始论述、评审意见与反驳、尚未复现的结果、标准组织的分歧记录。
- **反转藏哪**：被当作共识的，其实未定。多数人默认「已经定论」的地方，圈内仍在吵。
- **黑话样本**：随领域，如可复现性危机、scaling 是否见顶、P vs NP。
- **好案例**：一场有名有姓的公开论战，两边都给出可检验的论据。

## 9. 意义 — 它意味着什么

- **要回答**：理解这些之后，判断准则是什么；它改变了什么；该看哪些信号。
- **社会/人造读法**：应用与决策准则。
- **自然/形式读法**：影响与启发（它重塑了哪些认知、催生了什么）。
- **查什么**：领域内的最佳实践、决策框架、复盘与事后分析、后续影响。
- **反转藏哪**：直觉做法与有效做法相反；最省事的默认选择，往往是代价最高的那个。
- **黑话样本**：随领域，如可逆决策 vs 不可逆决策、探索与利用的权衡、涌现。
- **好案例**：一次「照直觉做而失败、按反直觉准则做而成功」的对照复盘。
